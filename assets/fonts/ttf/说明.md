# ttf/ —— 给非浏览器场景用的

`../*.woff2` 是给 HTML 演示用的（浏览器专用格式，体积小）。
这里的 TTF 是原始字重文件，用途是**装进 Windows 系统**，
这样 PowerPoint / Word / VS Code 里也能选到 Maple Mono CN。

## 安装

双击 `.ttf` → 点「安装」。或者全选三个文件右键 → 安装。

## 装完之后

字体族名是 `Maple Mono CN`，字重 400 / 500 / 700。

## 为什么只留了 3 个字重

Maple Mono 完整家族有 22 个字重（ExtraLight 到 ExtraBold，外加斜体），
每个 TTF 约 18MB，全装进去光字体就 400MB，没必要。

确实需要别的字重（比如做代码截图想要 Light 或 ExtraBold），
去 https://github.com/subframe7536/maple-font/releases 下
`MapleMono-CN.zip`，从里面挑对应的 ttf 就行。

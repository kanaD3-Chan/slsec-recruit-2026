# SLsec 招新宣讲 · 演示文稿

一份纯静态 HTML 演示，18 页（**开场片 + 17 页正文**）。

页序：开场片 → 我们是谁 → 破除误解 → 三大底牌 → 日常工作流 → 五大赛道总览
→ Web / Pwn / Reverse / Crypto / Misc（各一页）→ **现场演示（占位页）**
→ 上车路线 → 公费出征 → 怎么加入 → 你的第一个 flag → **开源凭证** → 收尾

> 第 16 页「开源凭证」的位置是刻意的：**放在收尾之前，不是之后**。
> 收尾那句「拒绝填鸭，只敬真知」是全场的情绪落点，观众最后该记住的是这句话，
> 不是两个网址。凭证紧挨着它前面——「该说的说完了，凭据也给你」，然后收在口号上。

## 怎么放

双击 `index.html`，用 Chrome / Edge 打开。**不需要服务器，不需要联网。**

> 如果想用 `file://` 之外的地址打开（比如投屏软件要求 http），
> 在文件夹里跑 `python -m http.server 8000`，然后访问 `http://localhost:8000`。

## 讲稿在哪

逐字稿有两份，内容一致，用途不同：

| | 用途 |
|---|---|
| `index.html` 里每页的 `<div class="notes">` | 演示时按 `S`，在演讲者窗口里滚动显示 |
| [`逐字稿.md`](逐字稿.md) | **单文件版**，方便打印、发群里、几个人分工各讲几页 |

`逐字稿.md` 是从 `index.html` 抽出来的，**页号与 deck 右下角一致**。
改完 deck 里的讲稿记得重新抽一遍（生成脚本见本文件末尾的注释）。

## 按键

| 键 | 作用 |
|---|---|
| `←` `→` | 翻页 |
| `空格` / `回车` | 第 0 页起播开场片；其它页没绑定 |
| `S` | **演讲者模式**（弹独立窗口：当前页预览 / 下一页预览 / 逐字稿 / 计时器，四张卡片可拖拽缩放） |
| `T` | 切换主题（本 deck 只做了一套终端主题，按了没反应是正常的） |
| `N` | 逐字稿抽屉（观众屏幕上贴底弹一条，慎用） |
| `F` | 全屏 |
| `O` | 缩略图总览 |
| `#/N` | 深链，直接跳到第 N 页（从 1 数起，`#/1` 是开场片） |

**演示前建议**：先按 `S` 把演讲者窗口拖到副屏，主屏全屏（`F`）。逐字稿只在演讲者窗口里显示，投影上不会出现。

## 开场片

第 0 页是招新视频（`assets/video/opening.mp4`，4K / 60fps / 19 秒）。

- 进这一页**不会自动播放**，是刻意的——你可以先讲两句再点。
- 点播放按钮、按空格或回车都能起播。
- 浏览器可能会拦截「带声音的自动播放」，这时封面会自己退回来等你点一下，不会静默失败。
- 翻到下一页会自动暂停并归零，下次回来是从头放的完整片子。
- 视频最后一帧是 CRT 关机收成一条白线，紧接着第 1 页就是黑底终端，中间没有跳感。

## 第 11 页：现场演示（占位页）

这一页是给「黑掉抓大鹅」那个环节**停住等**用的——讲者切到 Cheat Engine
去做内存扫描时，投影上留着它，观众知道接下来要发生什么、进行到第几步。

几个刻意的设计：

- **做得安静**。没有大色块、没有装饰，四步 runbook + 一行教学点。演示本身才是主角。
- **状态灯从 `REC` 换成 `LIVE`**，暗示现在是实时画面，不是在放片子。
- **第三步是全场唯一的教学点**：让数值变化再扫一次，候选地址从几万个收敛到几个。
  观众真正会记住的是这个收敛过程，不是最后改成多少。
- **底部那句是这一页存在的理由**：`这一步没有用到任何漏洞 —— 只是程序把关键数据放在了
  本地内存里，而内存你能改`。它把这场演示和前面 Pwn 那条赛道接上了，
  不然就只是一段炫技。

### 翻车预案（已内置）

现场演示是整场最容易出事的环节——游戏更新、投屏延迟、CE 被反作弊拦。
所以这一页挂了一份**录屏备份**：**按 `V` 浮出，按 `V` 或 `Esc` 关闭**。
平时完全隐藏，不占版面，也不会被观众看到。

录像有两个版本，靠 `<video>` 的多 `<source>` 自动选择：

| 文件 | 体积 | 进仓库 | 用途 |
|---|---|---|---|
| `assets/video/demo-backup-full.mp4` | 234 MB | ✗ gitignore | 本机投影用，画质满血 |
| `assets/video/demo-backup-lite.mp4` | 50 MB | ✓ | clone 下来时的兜底 |

浏览器按 `<source>` 顺序试，第一个加载不到就自动退到下一个。
所以**同一条 HTML**：你本地放的是高清版，别人 clone 下来看到的是 lite 版。

> 换录像时两个文件都替换即可，文件名别改。

## 改内容

正文全部在 `index.html` 里，每页一个 `<section class="slide">`，结构是：

```html
<div class="term-chrome">…</div>   <!-- 顶栏：红黄绿点 + 路径 + 页码 -->
<p class="term-prompt">whoami</p>  <!-- 命令行提示符 -->
<h2 class="term-h2">标题</h2>
<pre class="term-block">正文</pre>  <!-- 页面正文，保留换行 -->
<div class="term-foot">…</div>     <!-- 页脚 -->
<div class="notes">讲稿</div>      <!-- 只在演讲者模式里显示 -->
```

正文里的着色用 `<span>` 手标，四个类：`.c` 注释灰 / `.g` 绿 / `.y` 青 / `.p` 粉 / `.w` 琥珀 / `.hi` 白。

**注意 `notes` 里的内容观众永远看不到**，但也不要往页面上写"这一页想表达……"这种给自己看的话——页面只放观众该看的东西。

## 两个设计上的约定

1. **配色跟招新视频共用一套**（`#050505` / `#00FF66` / `#00D2FF` / `#FF2E63` / `#FFB300`）。视频和 PPT 连着放不会串味。改色只改 `assets/deck.css` 顶部的 `:root`。
2. **字体只用 Maple Mono CN**，`--font-sans` / `--font-serif` / `--font-display` 都指向它。这是纯终端风格 deck，靠字号和字重拉层次，不引入第二种族。四个字体变量定义在 `deck.css` 里而不是 `fonts.css` —— 因为 `base.css` 加载更晚会覆盖 `fonts.css` 的 `:root`。
